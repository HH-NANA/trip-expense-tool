출장 세부내역서 만들기

출장 유형을 고르고 증빙 이미지를 올리면, 계산 내역과 증빙이 포함된 엑셀을 만듭니다.

저장한 출장 내역 (–/20건)

입력값과 증빙 이미지를 현재 브라우저에 저장합니다. 같은 파일을 같은 위치에서 같은 브라우저 프로필로 열어 주세요.

1. 출장 기본 정보

출장 일수와 일차별 입력은 유지합니다. 일요일은 다시 계산하므로 공휴일과 날짜별 예외를 확인하세요.

등록한 시작일부터 복귀일까지 연속된 일정으로 계산합니다. 날짜가 끊기면 별도 건으로 작성하세요.

자차는 소노타워 출발, 네이버지도 ‘실시간추천’ 왕복거리와 통행료 증빙을 사용합니다. 식비가 포함되면 ERP에서는 국내출장으로 처리합니다.

해외출장은 기안이 완료된 산출내역서의 원화 지급액으로 임직원·여행사 지급분을 나눕니다. 국가별 여비·환율은 자동 산정하지 않습니다.

이 확인을 선택하고 모든 출장자의 날짜별 교통수단과 이동 순서가 일치하면, 일비를 제외한 항목에 최고 직급의 지급 기준을 적용합니다. 실제 결제 금액은 출장자별로 다를 수 있습니다.

2. 출장자별 비용·증빙

교통수단은 실제 순서대로 선택하세요. 모든 출장자가 전 일정에 회사차량만 이용하고 별도로 청구할 교통비가 없다면 교통비 증빙 행과 이미지를 추가하지 않아도 됩니다. 회사차량과 대중교통을 섞어 이용했다면 실제 이용한 유료 구간의 금액만 입력하세요. 일요일은 자동 표시되며, 그 외 공휴일은 직접 선택하세요.

교통비 비고의 공통 구간은 교통 출발지와 출장지를 사용합니다. 역·터미널 등이 다르면 출장자별 증빙 행에 실제 출발지와 도착지를 입력하세요.

자차 기준 운임 확인 순서: SRT(수서) → KTX(서울, 노선 없으면 용산) → 고속버스(동서울, 노선 없으면 강남). 기준 운임과 통행료는 각각 증빙합니다. 렌터카·쏘카는 지급 대상에서 제외합니다.

회사차량·동승 또는 전일 오후·익일 오전 조건의 일비 감액은 1/2을 한 번만 적용합니다. 일요일·공휴일에는 일비를 지급하지 않으며, 식비 감액 조건이 겹치면 적용 기준을 선택하세요. 택시·주차는 출장자별 합계에서 지급 일비 총액을 뺀 초과분을 적용합니다.

증빙 이미지는 PNG, JPEG, WebP를 지원합니다. 금액은 직접 입력하며 이미지 속 금액을 읽지 않습니다.

3. 출장 공통 교통비 증빙 (필요할 때만)

개별 승차권은 위의 출장자별 교통비 증빙에 올리세요. 이 칸은 여러 출장자가 함께 사용하는 증빙용입니다. 여기 올린 이미지는 엑셀에 ‘출장 공통’으로 표시되며 금액 계산에는 반영하지 않습니다.

4. 검산 및 엑셀 다운로드

    브라우저에서만 처리합니다. 엑셀 만들기는 다운로드만 합니다. 다음에 다시 쓰려면 저장 메뉴에서 ‘새 내역으로 저장’을 누르세요. 기준: 「사업본부 사무 업무 매뉴얼」 3-1~3-5, 3-11 및 동일 교통수단 동행 조건.
